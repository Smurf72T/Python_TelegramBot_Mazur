# Telegram-бот с функцией календаря

Проект представляет собой многопользовательский календарь-бот для Telegram, позволяющий пользователям создавать, просматривать, редактировать и удалять события. Бот интегрирован с Django-админкой и базой данных PostgreSQL.

## Функциональность
- Создание и управление событиями
- Просмотр списка событий и деталей
- Редактирование и удаление событий
- Приглашение участников на события
- Публичные и приватные события
- Статистика использования
- Экспорт данных в CSV и JSON

## Технологии
- Python 3.12
- python-telegram-bot 20.9
- Django 6.0.2
- PostgreSQL
- Docker

## Запуск проекта

### Через Docker (рекомендуется)
1. Убедитесь, что у вас установлены Docker и Docker Compose
2. Создайте файл `.env` в корне проекта (пример в `.env.example`)
3. Выполните команду:
```bash
docker-compose up --build
```
4. Бот запустится автоматически, Django-админка будет доступна по адресу http://localhost:8000

### Локальный запуск
1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Настройте переменные окружения в `.env`
3. Запустите Django-сервер:
```bash
cd django-admin-panel
python manage.py runserver
```
4. В другом терминале запустите бота:
```bash
python main.py
```
